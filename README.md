## 👨‍💻 About Me

I'm a **MERN Stack Developer** at **Bridgeon Solutions LLP**, based in Manjeri, Kerala, India — self-taught, and building in public.

- 🔭 Currently building **[Nesteeq](https://github.com/M32-Technologies)** — a multi-tenant apartment management SaaS (Next.js + Express/TypeScript/Mongoose) with role-based dashboards, invite systems, and secure auth
- 🧠 Deepening my expertise in **Node.js, TypeScript, and system design** — I gravitate strongly toward backend engineering
- 📚 Studied DSA, TypeScript, and Next.js internals through structured, self-driven learning
- 🌱 Sharing my journey on LinkedIn under **#LearningInPublic**
- 🎯 Actively exploring new opportunities as a backend/full-stack developer
- ⚡ Off-screen: Formula 1 racing and deep-sea exploration

## 🚀 Featured Projects

### 🏢 [Nesteeq](https://github.com/M32-Technologies) — Multi-Tenant Apartment Management SaaS
A production-grade SaaS with 8 role-based dashboards (`super_admin`, `property_manager`, `treasurer`, `owner`, `tenant`, and more), Better Auth with email OTP, cross-database resident lookups, and a secure invite system using SHA-256 token hashing with TTL-indexed cleanup.
`Next.js` `Express` `TypeScript` `MongoDB` `Better Auth` `TanStack Query`

### 🏟️ [BookMyVenue / Venuo](https://github.com/MuhammedRaneesh/Venue-Booking-) — Venue Booking Platform
A Kerala-focused venue booking platform with a full admin dashboard, MongoDB `$facet` aggregations, real-time Socket.io notifications, Razorpay advance-plus-balance payments with HMAC verification, BullMQ scheduled reminders, and Redis caching.
`React` `RTK Query` `Express` `MongoDB` `Redis` `BullMQ` `Razorpay`

### 👟 [STRIDE](https://github.com/MuhammedRaneesh/Project-Stride) — Sneaker E-Commerce Platform
My foundational full-stack project — built under the WeCode Community — establishing core patterns like modular architecture, centralized error handling, and JWT auth with httpOnly refresh tokens.
`MERN Stack` `JWT` `Redis`
